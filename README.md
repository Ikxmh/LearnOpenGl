"# LearnOpenGl"

I will be working on this project over a period of the time, so I can try to get more than just basic understanding of OpenGL. I did first learn about it at Centennial College, but I want to learn more about it.

A low-level C++ graphics sandbox built to explore core engine architecture and the graphics pipeline. This project focuses on moving past commercial engine buttons to understand explicit memory management, shaders, and 3D math.

I am working on this project with OpenGL (Core Profile), GLFW, GLAD, and VS 2022.
